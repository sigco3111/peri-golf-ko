# 페리 골프 한글화 (Peri Golf KO)

**비공식 한글화** — 카파도키아 요정 굴뚝 사이를 누비는 3D 물리 미니골프 *Peri Golf*의 한국어 버전입니다. 브라우저에서 바로 플레이할 수 있습니다.

- 플레이: https://sigco3111.github.io/peri-golf-ko/
- 원작 플레이: https://furkiozknn.github.io/peri-golf/

## 게임 소개

공을 눌러 뒤로 끌어당긴 뒤 놓으면 샷! 비둘기집 테라스에서 일출 능선까지, 요정 굴뚝·동굴집·도자기 물레·당나귀가 있는 12개 홀(코스 파 40)을 가능한 한 적은 타수로 완주하세요. 홀마다 별 3개(파 이하, 숨은 포도, 특별 도전)와 숨은 지름길, 오늘의 도전이 있습니다.

- 조작: 공을 눌러 뒤로 끌기 / 키보드 `←` `→` 조준 + `Space` 길게 눌러 충전 · 빈 땅 끌기로 카메라 회전 · `V` 조감 시점 · `C` 스코어카드 · `P`/`Esc` 일시정지 · `L` 언어 전환
- 언어: 한국어(기본) / English / Türkçe — 메인 메뉴·설정의 언어 선택 또는 HUD의 언어 버튼(KO → EN → TR), 선택은 브라우저(localStorage)에 저장됩니다. 주소 뒤에 `?lang=en` 처럼 붙여 강제할 수도 있습니다.

## 번역 용어

카파도키아 · 요정 굴뚝(페리 바카라르, Peri bacaları) · 동굴집 · 비둘기 계곡 · 지하 도시. 골프 용어는 파 / 버디 / 이글 / 보기 / 홀인원 / 타수. 홀 이름: 비둘기집 테라스, 요정 굴뚝 굽이, 동굴집, 도자기 공방, 모래 계곡, 지하 도시, 등불 통로, 포도밭 길, 돌다리, 도약, 비둘기 계곡, 일출 능선.

## 변경 내역 (원작 대비)

모든 변경은 `index.html`에 들어 있습니다. 게임 로직·물리·에셋은 수정하지 않았습니다.

- 한국어 사전 `I18N.ko` 추가: 영어 사전의 키 103개를 전부 번역 (메뉴, 설정, HUD, 12개 홀 이름, 특별 도전 문구, 결과·종료 화면, 오늘의 도전, 공유 문구, 안내 토스트). 인라인 Arena 키트의 접근성·공유 문구 17개도 한국어 추가.
- 언어 전환: 메인 메뉴·설정의 선택기에 `한국어` 추가, HUD 언어 버튼과 `L` 키는 KO → EN → TR 순환. 기본 언어는 한국어(저장된 선택이 있으면 우선).
- 하드코딩 문구를 사전으로 이동: 홀 시작 배지(원작은 언어를 바꿔도 터키어 고정), 홀 버튼의 `Par`, 문서 제목, 로딩 문구.
- 글꼴: 시스템 글꼴만 사용 (`Pretendard`, `Noto Sans KR`, `Apple SD Gothic Neo`, `Malgun Gothic`). 외부 글꼴 요청 없음. 한글에서 대문자 변환·자간·줄바꿈이 깨지지 않도록 CSS 보정(`html[lang="ko"]`).
- 메타 태그(설명, Open Graph)와 공유 URL을 한글화 저장소 주소로 변경, 메인 메뉴 하단에 한글화 크레딧 추가.
- 제작자의 방문 통계(GoatCounter) 스크립트를 제거했습니다. 이 사이트는 외부 분석 서비스에 아무것도 보내지 않으며, 클리어 후 👍/👎 피드백 창은 끕니다.
- 외부 요청: 게임 엔진 Three.js r170을 jsDelivr CDN(`cdn.jsdelivr.net`)에서 불러옵니다 (원작과 동일). 결과 화면의 `다른 게임` 버튼은 원작 제작자의 게임 모음 사이트로 연결됩니다.
